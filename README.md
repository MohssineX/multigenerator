# multigenerator

![Python](https://img.shields.io/badge/python-3-blue)
![License](https://img.shields.io/badge/license-GPLv3-blue)
![Stars](https://img.shields.io/github/stars/MohssineX/multigenerator?style=social)

A lightweight terminal utility for generating strong and random passwords.

## Features

* Generates secure, random passwords using cryptographically strong randomness
* Custom password length, from 16 up to 32 characters
* Mix of uppercase, lowercase, numbers, and symbols for stronger passwords
* Input validation to prevent invalid or unsafe length choices

## Supported Platforms

- Windows
- Linux
- macOS

## Requirements

* Python 3.6 or later
* Terminal with ANSI escape sequence support

## Installation

### Clone the repository :

```bash 
git clone https://github.com/MohssineX/multigenerator.git
cd multigenerator
```

## Usage

Run the program :

```bash 
cd src
```

```bash 
python multigenerator.py
```

If your system uses `python3` :

```bash 
python3 multigenerator.py
```
